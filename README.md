# Islamic Queries and ChatGPT Responses

This repository accompanies the paper *Understanding Technology from the Lens of a Mufti: Design Guidelines for HCI4D* (under review). It contains the queries we showed to religious scholars in our interview study and the ChatGPT responses the scholars evaluated.

## Contents

| File | Description |
|---|---|
| `Queries_and_ChatGPT_responses.xlsx` | 32 Islamic queries, each in English and Roman Urdu, with ChatGPT's response in Roman Urdu and English. |

## Columns

| Column | Description |
|---|---|
| Number | Query number (1 to 32), matching the numbering in the paper's appendix. |
| Category | One of six question categories (see below). |
| Original Source | The Islamic question-and-answer website the query was drawn from. |
| Question (English) | Our English translation of the query. |
| Question (Roman Urdu) | The query as posed to ChatGPT. |
| Example Response (Roman Urdu) | ChatGPT's response, in Roman Urdu. |
| Example Response (English) | Our English translation of ChatGPT's response. |

## Categories

| Category | Queries |
|---|---|
| Theological concepts | 1 to 5 |
| Historical and cultural contexts | 6 to 11 |
| Personal identity and spirituality | 12 to 17 |
| Religious practices and worship | 18 to 22 |
| Legal and jurisprudential inquiries | 23 to 27 |
| Women's religious experience | 28 to 32 |

The categories follow the religious topics identified by Alam et al. (FAccT 2025) in their study of ChatGPT use for Islamic questions.

## How the queries were prepared

We drew the queries from Islamic question-and-answer (fatwa) websites. To reduce exact-text matching with the published fatwas, and so the likelihood of ChatGPT reproducing the original answers, we standardized each query into Roman Urdu and lightly rephrased its wording while preserving its meaning. Two researchers, both native Urdu speakers familiar with Hanafi jurisprudence, checked that each adapted query kept its original meaning.

## How the responses were generated

We submitted each query to ChatGPT once, in a logged-out incognito session to avoid account-specific personalization, and kept the first response. The exact model version could not be verified. ChatGPT's responses can vary between runs and model versions, so the responses here may differ from what ChatGPT returns today.

During the interviews, scholars reviewed the responses in Urdu script. The Roman Urdu and English versions in this file are provided for readers.

## Notes

- The English translations of queries and responses are ours. Islamic terms are kept in transliteration where no English equivalent is exact.
- The responses are ChatGPT's output, not religious guidance. They are shared for research purposes only and should not be used as rulings (fatwas).
- The study involved 15 religious scholars in Pakistan. No interview data or participant information is included in this repository.
